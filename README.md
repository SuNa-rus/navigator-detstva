# Навигатор детства

Цифровая платформа медицинского информирования и образовательной поддержки родителей.

**Заказчик:** ГАУЗ «Нижнекамская детская районная больница с перинатальным центром».

**Текущая версия:** MVP 0.3.1

## Основные направления

### Цифровая школа родителей

- Каталог образовательных материалов
- Поиск и категории
- Просмотр статей
- Создание материалов редакторами
- Проверка статей медицинскими работниками
- Возврат статей на доработку
- Публикация после проверки
- Новые статьи отображаются первыми

### Цифровой маршрут ребёнка

- Возрастные этапы
- Информация для родителей
- Отметки ознакомления
- Сохранение прогресса

## Роли пользователей

| Роль | Возможности |
|---|---|
| parent | Чтение статей и изучение маршрута |
| editor | Создание и редактирование материалов |
| medic | Проверка и публикация материалов |
| admin | Административные права |

## Локальный запуск

```powershell
python -m venv backend\.venv
& ".\backend\.venv\Scripts\python.exe" -m pip install -r backend\requirements.txt

Set-Location backend
& ".\.venv\Scripts\python.exe" -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Сайт: http://127.0.0.1:8000/

API: http://127.0.0.1:8000/docs

## Автоматические тесты

Из корня проекта:

```powershell
& ".\backend\.venv\Scripts\python.exe" -m pytest backend/tests -v
```

## Назначение тестовых ролей

Сначала зарегистрируйте пользователя через сайт.

Затем из папки backend:

```powershell
& ".\.venv\Scripts\python.exe" -m app.set_role demo_editor editor
```

Доступные роли: parent, editor, medic, admin.
